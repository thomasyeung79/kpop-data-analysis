📊 K-pop Industry Strategy Analysis System

A data-driven dashboard that analyzes the K-pop industry from multiple dimensions, including company structure, artist type, generation trends, and market focus.

Built with Python and Streamlit, this project combines data visualization, interactive filtering, and AI-style insights to explore strategic differences between major K-pop companies.


---

🚀 Features

📊 Dashboard Mode

Interactive filtering (artist type, gender, generation, market)

Company-based analysis (SM, JYP, YG, HYBE, Others)

Key visualizations:

Artist distribution by company

Group vs Solo comparison

Debut year trends

Market focus analysis



🏢 Company Comparison

Artist count by company

Group vs solo structure

Generation distribution

Market strategy comparison


🚀 Market Expansion Analysis

Visualizes how companies distribute artists across different markets

Highlights strategic focus of each company


🤖 AI-Style Insight Generator

Automatically generates industry insights based on selected data

Simulates analyst-style summary using rule-based logic


🎯 Custom Analysis

Allows users to filter data by specific markets

Supports focused exploration of industry segments


📖 Story Mode

Converts data into structured narrative

Explains:

Industry overview

Company strategy differences

Market trends

Final insights




---

🧠 How It Works

The system:

1. Loads a curated dataset of K-pop artists


2. Classifies:

Company groups (SM, JYP, YG, HYBE, Others)

Generations (1st → 5th Gen)



3. Applies user-selected filters


4. Generates:

Visual analytics

Company comparisons

Strategic insights



5. Provides:

Dashboard exploration

Storytelling mode

AI-style analysis

📊 Dataset

This dataset is manually curated for educational and analytical purposes.

It includes:

K-pop groups and selected solo artists

Company affiliations

Debut year

Gender

Primary and secondary markets


⚠️ Notes:

Only officially recognised and currently relevant artists are included

Major companies (SM, JYP, YG, HYBE) are grouped separately

Other companies are grouped under "Others" for comparison
